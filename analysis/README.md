# Analysis

Statistics of the test runs in [`data/`](../data/) and comparison with the preliminary model in [`poster/`](../poster/):
log-distance path-loss fit with 95 % confidence intervals, Wilson intervals for delivery ratios, delay statistics and the
Kolmogorov–Smirnov test, clock drift by linear regression, battery life from measured currents.
See [method.md](../docs/method.md#statistical-methods).

In WP5 the preliminary model is copied here from the frozen archive [`poster/`](../poster/) and run with the measured
values; `poster/` itself is not changed.
